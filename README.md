# 🎬 OTT Streaming Content Trend Analysis

## 📌 Veda Technology – Data Analytics Internship

This project is completed as part of the **Veda Technology Data Analytics Internship – Day 31**.

The project focuses on analyzing OTT streaming content data to identify patterns and trends in:

- Content types
- Genres
- Ratings
- Release years
- Content-added trends
- Countries
- Movie duration

The analysis converts raw OTT catalog data into meaningful visual insights that can support content acquisition and content strategy decisions.

---

## 🎯 Objective

The main objective of this project is to perform Exploratory Data Analysis (EDA) on OTT streaming content and identify useful trends from the dataset.

The analysis focuses on understanding:

- Which content type is more common?
- Which genres are most represented?
- How has content release changed over the years?
- Which countries contribute the most content?
- What are the common content ratings?
- How is movie duration distributed?
- How has the OTT catalog grown over time?

## 📊 Analysis Performed

### 1. Movies vs TV Shows

Comparison of the number of Movies and TV Shows available in the dataset.

### 2. Genre Analysis

Identified the most frequently represented genres in the OTT catalog.

### 3. Release Year Trend

Analyzed how the number of released titles has changed over the years.

### 4. Content Added Trend

Analyzed the yearly growth of content added to the platform.

### 5. Rating Distribution

Studied the distribution of content ratings.

### 6. Country Analysis

Identified countries with the highest number of titles.

### 7. Movie Duration Analysis

Analyzed the distribution of movie durations.
